# Grid Heist: Blackout Protocol

## Project Description

This repository contains my DAT602 Database Application Development assignment project, **Grid Heist: Blackout Protocol**.

For this project, I developed a database-driven multiplayer game using C# Windows Forms and Microsoft SQL Server. The game allows players to move around an 8×8 grid, collect items, earn points, and compete to reach the exit.

The main purpose of this project is to demonstrate how a C# application can interact with a SQL database to manage player accounts, game movements, inventory, scoring, and administrative functions.

## Repository Contents

This repository includes:

- C# Windows Forms Application – The game interface, including login, gameplay, and administrator screens.
- SQL Scripts – Database tables, relationships, stored procedures, and test data.
- Data Access Classes (DAO) – Classes used to connect the application to SQL Server.
- Database Design – Entity Relationship Diagram (ERD) and database structure.
- Project Documentation – Assignment reports covering the design, implementation, and testing of the application.

## Technologies Used

- C# and .NET
- Windows Forms
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
- Visual Studio
- Git and GitHub

## Project Purpose

Through this assignment, I aimed to improve my understanding of database design, SQL stored procedures, CRUD operations, and connecting a database to a working application. This repository records my development work and progress throughout the assignment.
